# Kuroda Autobody

Website for Kuroda Autobody, a family-owned collision repair shop in Waipahu, Oʻahu (since 1938).

Astro 7 + Tailwind v4, Sanity for the blog, Vercel for hosting.

**Start here:** [ONBOARDING.md](./ONBOARDING.md)

```
npm run dev      # localhost:4321
npm run build    # production build
npm run check    # astro check + eslint + prettier
npm run studio   # Sanity Studio (studio/)
```
